# java-calculator-precourse

### ⚙️ 기능 목록
- [ ]  사용자로부터 문자열을 입력받는다.
- [ ]  커스텀 구분자가 있는지 확인한다.
    - [ ]  커스텀 구분자가 올바른 형식인지 검증한다.
        - [ ]  커스텀 구분자를 추가로 지정한다.
- [ ]  구분자 기준으로 문자열에서 숫자를 분리한다.
    - [ ]  분리한 숫자가 유효한지 검증한다.
        - [ ]  숫자가 빈 문자열이면 0을 반환한다.
- [ ]  분리한 숫자를 모두 더한다.
- [ ]  결과를 출력한다.

### 💥 예외 사항
사용자가 잘못된 값을 입력할 경우 `IllegalArgumentException`을 발생시킨 후 애플리케이션은 종료되어야 한다.

- [ ]  커스텀 구분자가 올바른 형식이 아닌 경우
    - [ ]  커스텀 구분자 지정 형식이 `//<구분자>\\n` 가 아닌 경우
    - [ ]  커스텀 구분자 지정 구문이 문자열 맨 앞에 있지 않은 경우
    - [ ]  커스텀 구분자의 길이가 1이 아닌 경우
        - 길이가 2 이상인 구분자 지정이 가능하다면, -가 포함되어 (예: `//,-\\n1,-2,-3`) 음수 판단을 할 수 없는 경우가 생긴다. 기본 구분자가 한 문자인 것도 고려하여 커스텀 구분자의 길이는 1로 제한하였다.
        - 커스텀 구분자가 빈 문자열이거나, 문자+공백인 경우도 예외 사항으로 처리한다.
            - 커스텀 구분자가 빈 문자열이면 입력된 숫자가 한 자리씩 분리되므로 한 자리 이상인 숫자는 더할 수 없게 된다. 숫자 계산이 의도대로 동작하지 않을 가능성이 높기 때문에 이 경우는 허용하지 않는다.
        - 커스텀 구분자가 공백 문자 하나인 경우는 허용한다.
- [ ]  구분자 기준으로 분리한 문자가 유효한 숫자가 아닌 경우
    - [ ]  분리한 문자가 숫자가 아닌 다른 문자인 경우
    - [ ]  분리한 문자가 양수 외의 숫자(0 또는 음수)인 경우
    - [ ]  분리한 문자가 공백이거나 공백을 포함하는 경우

### 🪶 그 외 구현 사항
구분자와 숫자의 배치는 상관없이, 구분자에 의해 분리되는 숫자들을 모두 더하는 계산기로 동작하도록 기능을 구현하였다.

- [ ]  구분자 앞이나 뒤에 숫자가 없는 경우도 허용한다. (예: `1::2`, `:1:`, `:`)
    - 만약 문자열이 `1::2`라면, 구분자 기준으로 분리하면 [”1”, “”, “2”]가 된다. 문제 예시에서 빈 문자열은 0을 반환한다고 하였으므로 예외 사항이 아니라고 판단했다.
- [ ]  구분자 없이 숫자만 있는 경우, 그 숫자를 반환한다. (예: `//;\\n1)`)
    - 테스트 코드 예제를 참고하였다. 구분자로 분리되어 있지 않아도 숫자가 있다면 반환한다.
- [ ]  기본 구분자와 커스텀 구분자는 함께 사용할 수 있다.
    - 커스텀 구분자를 지정하면 기본 구분자는 사용할 수 없게 하는 것이 어색하다고 생각하여 허용하였다.
